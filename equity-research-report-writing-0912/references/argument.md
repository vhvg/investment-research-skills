# 论述组织：让材料围绕一个问题逐步展开

## 先判断本节做什么

“介绍了很多信息”和“完成了论证”有区别。用户给出“供应链有优势”时，先从材料识别具体优势：是开发响应、订单切换、生产配套、成本，还是稳定交付。只有产能规模数据，就围绕规模与布局展开；有工序和订单资料，才能进一步解释响应方式。

不把输入材料的排列顺序直接当作正文顺序。将相同问题的材料放在一起；把理解后文所必需的业务定义、基准与背景放在前面。内部可以用一句话描述每段的作用，但不把内部标签输出成正文。

## 按论述关系组织，不按固定段数写

| 本节的问题 | 可采用的展开路径 | 样本定位 |
|---|---|---|
| 一个经营模式为什么有效 | 传统做法及其约束 → 公司怎样组织业务 → 哪个环节发生变化 → 观察到的结果或适用条件 | R23，PDF 11—12页 |
| 制造能力的差异在哪里 | 客户或产品要求 → 开发/生产难点 → 公司的工序与组织 → 可比证据 | R06，22—23页；R31，14—15页 |
| 改革怎样落实 | 原有问题 → 管理或经营动作 → 配套变化 → 已实现结果与后续计划 | R07，41—43页 |
| 行业为何出现分化 | 确立比较维度 → 按同一维度比较 → 解释差异形成条件 → 对象各自的阶段判断 | R22，9—11页；R26，16—17页 |
| 多个因素怎样共同起作用 | 总体判断 → 同层因素分别展开 → 必要的关系归纳 | R21，19—20页；R33，25页 |
| 业务有多大空间 | 当前基数 → 可比对象与差异 → 明确假设 → 对应的测算结果与实现路径 | R10，8—9页；R19，10—11页 |
| 利润变化如何解释 | 主要变化 → 各项因素的作用对象及期间 → 一次性与持续性因素 → 给定的展望 | R29，13页 |

这些是材料允许时的选择。用户已经给定完整论证顺序时优先保留；不要把每条路径扩展成必备章节，更不要在每段机械重复整条链路。

## 段落要有不同的贡献

连读小节，判断每一段是否新增了一层内容：解释一个环节、提供一个关键比较、展开一项举措、说明一个阶段，或处理影响判断的限制。

例如，讨论产品开发，第一段可以说明传统开发提前量为何带来预测压力；第二段再说明门店反馈如何进入设计与追单；第三段进一步说明设计师、区域经理和采购怎样协作。若三段都只说“响应迅速、效率较高”，就需要回到材料重组，而非换词。

承接应来自研究对象或经营关系。前段讨论产品反馈，后段可以直接写反馈怎样影响开发；无需用“进一步来看”“值得注意的是”替代实质连接。转向另一问题时，明确新的主语或观察维度，必要时设置小节标题。

同一过程被图表隔开时，文字仍然连续。图后接着解释下一环节，不重新介绍公司。图表本身已经完整呈现的长序列不逐项朗读；保留支撑本段判断的关键数据和差异。

## 因果、比较、时序与预测各有写法

### 因果

解释到业务动作：谁改变什么安排，影响了哪个经营环节。使用“带动、改善、降低”等结果动词，需要材料支持对应结果。只有机制或计划时，用“有助于、旨在、公司计划”等与证据相符的说法。

有机制资料时应充分解释，不为了谨慎把所有分析退回到数字罗列；没有机制资料时，不用行业常识替公司补写具体动作。一个比率改善与一项改革同时发生，不足以写成该改革全部贡献了改善。

### 比较

先固定比较维度，再比较对象。可以对同一家公司分别与欧洲高端制造商、亚洲规模制造商比较，但要分别说明研发、工艺、订单批量等维度，不能混成笼统的“全面领先”。

跨公司归纳时，选取有差异的案例解释同一个问题。先后堆叠几家公司的发展史不能自动形成行业结论。案例只能支撑相应范围的判断；不把有限案例归纳成“所有成功公司都必须如此”。

### 时序

历史阶段保留转折条件、采取的动作和经营变化。用户给定的关键年份保留，重复年份可以由时间线承担。不得把“此后增长”直接改成“因此增长”，也不得把历史时点的“目前”带入新报告的当前状态。

### 预测和测算

假设与结果相邻，能让读者知道结论在什么条件下成立。公司指引、作者预测和情景测算分别归属，不把中长期潜在规模写成下一年的收入目标。

测算仅使用用户给定或本次材料明确的输入。算术发现矛盾时保留原始值并提示；不要为让论证顺畅静默修改数据或补入假设。只有研究方向、没有可用参数时，可以写定性的增长路径。

## 区分公司深度、行业专题与跟踪正文

公司深度可以按问题组织经营机制、竞争优势与增长来源。公司概况段只需交代理解后文所必需的业务身份和规模，无须提前塞入所有投资结论。

行业专题围绕变化、竞争要素或跨公司规律组织。公司案例服务于横向问题；样本中的并购专题在案例复盘之后归纳方法，日本出海专题先给比较框架再展开案例，两种顺序均可成立。

跟踪报告围绕本次新增事实、变化幅度和影响时期组织。读者已知的背景适当压缩；“财务梳理”与“经营改革”不能为了套用公司深度结构重复一遍。

## 小节标题与段首

标题提供阅读方向，段首进一步说明本段内容。两者可以相关，但不要逐字重复。主要分析段落通常先概括发现；解释复杂业务概念、承接上文或交代事件时，可以先写事实。

并列因素清楚且各有展开时，可以编号或列项。长篇经营论述仍需完整句段。不要把原文的一项编号误当作一段只能写一句，也不要将每个完整段首句升级为独立标题。

## 发现材料缺口时

缺口影响核心结论：在对应判断中说明条件，或将无法支持的部分暂列待补；不将假设写成已验证结论。

缺口不影响当前论述：完成可写内容，不在每段末尾添加“有待进一步验证”。与本节无关的数据缺失不扩大为一项新研究任务。
