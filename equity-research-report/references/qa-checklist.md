# 交付前质量门槛

## 阻断项

任一项未通过时不得把报告描述为完成：

- 核心结论缺乏可回溯证据或把推断写成事实。
- 存在未处理的 `[[占位符]]`、待核实数字或虚构来源。
- 数据截止日、价格基准日、币种或预测口径不明确。
- 图表、正文、模型和封面中的关键数字不一致。
- 完整或详细报告包含图表，但未提供图表底稿；或报告图/表无法映射到唯一工作表。
- 估值没有方法、基准日、关键假设或股本/净债务桥接。
- 报告缺少风险与证伪条件。
- DOCX 未完成最终渲染检查，或存在遮挡、截断、缺字和不可读图表。

## 研究审计

- [ ] 研究问题和受众明确。
- [ ] 三至五条核心假设可证伪。
- [ ] 核心证据优先来自原始资料。
- [ ] 事实、测算、预测和判断已区分。
- [ ] 来源冲突和资料缺口已解释。
- [ ] 每条主要判断有反方证据或替代解释检查。
- [ ] 当前信息已按数据截止日重新核验。

## 论证审计

- [ ] 标题和目录单独阅读即可理解逻辑。
- [ ] 每章都服务于核心论点、估值或风险。
- [ ] 每条论点包含机制、证据、财务影响和证伪条件。
- [ ] 市场共识与报告新增判断已分开。
- [ ] 催化剂包含时间、事件、预期影响和跟踪指标。

## 数字与模型审计

- [ ] 历史数据与披露一致，重述项目已说明。
- [ ] 分部、地区和渠道加总与集团口径一致。
- [ ] 收入、利润、现金流和净债务桥接完整。
- [ ] A/E、财年、币种、单位、同比/环比和百分比/百分点一致。
- [ ] 预测假设具有历史锚点或外部依据。
- [ ] 情景方向合理，敏感性公式和每股价值无硬编码错误。
- [ ] 可比公司筛选、估值年度和异常值处理有理由。

## 图表与引用审计

- [ ] 每张图表有编号、标题、单位、期间和来源。
- [ ] 自行测算和预测已标记。
- [ ] 每张图表在正文中被解释。
- [ ] 图例、坐标、颜色和预测区可读且不误导。
- [ ] 截图包含平台、日期、样本和筛选条件。
- [ ] 引用定位足以让另一位研究者复核。
- [ ] `图表索引` 中每张报告图/表只出现一次，并对应唯一 `Fnn_`、`Tnn_` 或 `Inn_` 工作表。
- [ ] 每个图表工作表前几行均填写完整原始链接，没有只写“公司资料”“行业数据”等模糊来源。
- [ ] 来源行以下的数据保持适合原始资料和分析目的的结构，没有为了套模板而强行使用统一列名、固定列数或固定方向。
- [ ] 数据图使用可复算数据和公式，未仅粘贴静态截图；图片的样本边界和复用限制已在证据台账或报告注释中记录。
- [ ] 报告图题、来源行、数字、A/C/E 标记和底稿索引一致，不存在孤立图表或孤立工作表。
- [ ] 关键图表工作表已渲染检查，数值和图形无截断。

## 编辑与成品审计

- [ ] 投资逻辑、预测和估值段前置结论；历史与经营复盘段在段内或紧邻段落完成阶段判断。
- [ ] 删除重复事实、空泛形容和无关历史。
- [ ] 公司、品牌、人名、币种和缩写拼写一致。
- [ ] 风险写明传导路径和观察指标。
- [ ] 封面、目录、正文、附录和来源清单完整。
- [ ] 分段撰写产生的章节已合并至唯一主稿，进度文件中的口径、图表编号和章节状态与主稿一致。
- [ ] 未伪造机构品牌、分析师身份、评级认证或合规文本。
- [ ] 对外部读者说明研究用途、数据截止日和关键限制。

## 语言与句法审计

- [ ] 每句可识别为事实、样本、测算、预测、判断或风险，措辞强度与证据层级一致。
- [ ] 常规成稿用“根据披露/样本显示/在假设下”自然区分认识层级，没有连续使用 `【披露事实】` 等审计标签。
- [ ] 每个关键句写清主语、期间、口径、指标和比较基准，不用“高增、显著、强劲”替代数字。
- [ ] “我们认为/判断/预计”只用于跨越证据边界，没有成为段落起笔口头禅。
- [ ] 同一句没有叠加“可能、或将、有望”等多个不确定性标记。
- [ ] “主要系、受益于、带动、推动”后的因果关系有证据或明确标为判断。
- [ ] 每段只完成一种主要功能；出现多个独立结论、多个段首标签或频繁认识层级换挡时已拆分。
- [ ] 超过 120 字的句段已检查，复杂并列改用分号、`①②③` 或拆句。
- [ ] 相邻段落没有反复以“我们认为、同时、此外、其中”起笔。
- [ ] 标题包含研究对象和方向性结论，只读目录可以复原论点树。
- [ ] 删除“前景广阔、值得期待、持续赋能”等无法由事实证明的套话。
- [ ] 经营章节使用量价、品类、地区、渠道、客户、产能、店效或利润率等可验证变量，而非只写抽象“品牌力/空间”。
- [ ] 图表正文只解释趋势、结构和含义，没有逐项复读图中全部数字。

## 图表底稿视觉与公式审计

- [ ] 所有报告图/表对应工作表均已逐张预览，数据和图形完整可见。
- [ ] 工作表结构保持轻量；顶部来源清楚，下面的数据和图形布局服从实际内容而非固定模板。
- [ ] 公式无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或意外循环引用。
- [ ] 历史、预测和一致预期具有稳定颜色/标记，单位和小数位一致。
- [ ] 关键假设位于可见单元格；其来源在证据台账或独立模型记录，公式中没有未说明的魔法数字。
- [ ] `scripts/validate_chartbook.py` 通过；任何允许保留的警告已有说明。

## DOCX 视觉审计

- [ ] 页数符合预期，目录页码可更新。
- [ ] 页眉、页脚、章节起始页和页码正确。
- [ ] 标题不孤行，图题与图表、来源与图表尽量同页。
- [ ] 表格允许自然增高并正确跨页，表头可重复。
- [ ] 没有缺失中文字形、文字重叠、图片变形或低清晰度。
- [ ] 100% 缩放下正文、图例、轴标签、脚注和来源可读。
- [ ] 最终一次修改后已重新渲染并逐页检查。
