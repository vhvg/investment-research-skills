## 来源优先级

按以下顺序寻找证据，并尽量回到原始来源：

1. 公司及监管原始资料：年报、季报、公告、招股书、业绩会材料、电话会原文、监管备案、交易所披露。
2. 官方与准官方资料：政府、统计局、央行、行业主管部门、国际组织、行业协会和正式标准。
3. 高质量数据库和行业机构：注明数据库、指标定义、更新时间和是否为一致预期。
4. 主流媒体、专业媒体和研究机构：用于补足访谈、事件和行业背景，保留原始链接与发布日期。
5. 渠道和用户信号：官网、官方旗舰店、门店观察、电商数据、招聘、社交媒体和论坛；只代表相应样本与时点。

公司官网的营销表述可证明公司如何定位产品，不能独立证明产品领先。用户评论可显示问题或偏好，不能直接外推市场份额。

## 官方文件发现与留档

先从发行人和交易所/监管机构建立完整文件清单，再按研究问题读取：

- 美股：SEC EDGAR 的公司 submissions、10-K、10-Q、8-K、DEF 14A、Form 4 和正式附件；记录 CIK、accession number、filing date 与报告期。
- 港股：港交所披露易的年报、中报、业绩公告、通函和权益披露；记录公告编号、发布日期和财务期。
- A 股：上交所、深交所、北交所、巨潮资讯和公司官网；记录公告编号、发布日期和报告期。
- 其他市场：优先使用当地交易所、证券监管机构和发行人投资者关系网站。

不要把搜索结果摘要当原始资料。条件允许时把原始 HTML/PDF/XBRL 下载到任务目录，保留文件名、URL、下载时间和 SHA-256；若不能留档，至少保存稳定 URL、文档编号和页码/章节定位。每次更新先检查是否出现更晚的财报、修订文件或重大事件公告。

## 证据台账

为每项关键证据记录以下字段：

| 字段 | 要求 |
|---|---|
| ID | 使用稳定编号，如 S001 |
| 命题 | 该材料支持或反驳的具体命题 |
| 类型 | 事实 / 测算 / 预测 / 判断 |
| 来源 | 机构、文件或网页名称 |
| 日期 | 发布日期与数据截止期 |
| 定位 | 页码、表格、章节、URL 或原文位置 |
| 原始值 | 保留原单位和口径 |
| 标准值 | 统一币种、单位和期间后的值 |
| 处理 | 汇率、年化、去重、重分类等步骤 |
| 置信度 | 高 / 中 / 低及理由 |
| 使用位置 | 报告章节、图表编号、底稿工作表或模型单元 |

不要只保存搜索结果摘要。保存能让另一位研究者复核的原始定位。

## 事实、测算、预测与判断

- 事实：来源直接披露或可观察的数据。使用“公司披露”“根据……数据”。
- 测算：依据公开数据计算出的历史或现状值。使用“我们测算”，并给出公式和假设。
- 预测：对未来的模型结果。使用 `E`、预测区间和关键假设。
- 判断：对机制、持续性或估值的解释。使用“我们判断/认为”，同时写出证据和证伪条件。

不得把媒体报道的匿名消息写成公司已确认事实。不得把一致预期标成研究者自有预测。

## 品牌营销材料分级

按材料能证明的范围使用：

| 材料 | 可以证明 | 不能单独证明 | 默认置信度 |
|---|---|---|---|
| 官方产品页/目录 | SKU、标价、官方功能主张、上架状态和抓取时点 | 技术优越性、实际销量、消费者接受度 | 中 |
| 官方新闻稿/社交账号 | 活动、代言、联名和品牌叙事已发布 | 营销效果、转化率、长期品牌力 | 中低 |
| 投资者材料/管理层讲话 | 管理层目标、口径和战略表述 | 目标已实现、独立行业结论 | 中至高，视披露约束 |
| 电商店铺与截图 | 特定平台、店铺和时点的商品、标价、折扣与评论样本 | 全渠道 ASP、销量、库存和市场份额 | 低至中 |
| 用户评论/论坛 | 具体痛点、偏好和待验证线索 | 总体客群画像、产品质量结论 | 低 |

用第三方测试、渠道数据、财务结果或多时点样本交叉验证营销主张。正文中写明材料性质，不把“品牌称”改写成客观定论。

## 数据标准化

在进入图表或模型前统一：

- 财年和自然年、季度和累计期、报告币种与交易币种。
- 百分点与百分比、同比与环比、名义值与实际值。
- 收入与流水、出货与零售、门店数与销售网点、订单与确认收入。
- 持续经营与报表口径、调整前与调整后利润、归母与少数股东损益。
- 历史 `A`、一致预期 `C`、研究预测 `E`。

保留原始数据列和转换列。任何汇率换算都记录汇率日期与来源。

## 引用与图表来源

- 把引用放在支撑的句子、段落或图表附近，不把整章来源堆到报告结尾。
- 每张图和每张表单独写“资料来源”，多来源用逗号分隔。
- 自行计算时写“资料来源：……，研究者测算”，预测时明确“研究者预测”。
- 使用访谈或调研时写明对象类型、日期、样本数和限制；没有真实调研就不要使用“草根调研显示”。
- 截图写明平台、店铺、检索日期、地区和筛选条件。
- 完整报告同时维护 [chart-data-workbook.md](chart-data-workbook.md) 规定的 XLSX。每个图/表在 `图表索引` 中有唯一行，并对应唯一底稿工作表。
- 每个图表工作表在最前面几行填写完整原始 URL，多来源逐行增加；来源行以下不规定数据格式。发布日期、页码、口径、处理步骤等详细审计信息继续放在证据台账或独立模型。
- 外部图片和截图的原始页面链接放在对应图片工作表顶部；页面/账号、抓取时点、样本边界和复用限制放在证据台账或报告注释。图片只能证明对应样本与时点。

## 冲突和缺口处理

遇到来源冲突时：

1. 检查期间、币种、统计范围、是否含税和是否为流水。
2. 优先采用定义清楚、接近原始披露且时间最新的来源。
3. 在报告中说明无法消除的差异和所选口径。
4. 对结论做区间或情景分析，不强行给出单点精确值。

关键数据缺失时允许使用测算，但必须展示公式、替代变量、假设依据和误差方向。若缺口会改变核心结论，把它列为未解决问题。

## 完整性门槛

进入正式写作前确认：

- 每条核心论点至少有一项高质量直接证据和一项交叉验证。
- 每个关键预测驱动都有历史基准或外部锚点。
- 每个估值输入都可回溯到模型、市场数据或明确假设。
- 每项重大风险都对应一个可观察指标。
- 数据截止日、价格基准日、币种和预测口径已锁定。
- 每张计划进入报告的图/表已有稳定编号、底稿工作表和来源定位；不存在只有图片、没有可复算数据的数据图。
