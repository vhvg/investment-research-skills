# 正文段落、图表与页面格式

## 先决定文本层级

同时读取 [chinese-sell-side-prose.md](chinese-sell-side-prose.md)。默认采用参考报告的连续正文结构：章节标题、二级小节、段内加粗完整领句、常规说明文字。不要将段首句提升为目录标题，也不要把普通分析段排成项目符号卡片。

| 元素 | Markdown | Word/PDF |
|---|---|---|
| 报告标题 | `#` | Title样式 |
| 一级章节 | `##` | Heading 1，可统一编号 |
| 二级小节 | `###` | Heading 2，确有小节才设置 |
| 正文领句 | `**完整概括句。**` 后紧接正文 | 同一段落内的加粗run，非Heading样式 |
| 正文 | 一个自然段一块，段间一个空行 | 统一正文样式、首行缩进、段间距 |
| 图题/表题 | 独立题注行 | Caption样式 |
| 来源与注释 | 图表后独立行 | Source/Note样式 |

四级及更深标题仅用于确有必要的复杂结构；一般不用于几十字的说明。编号形式全文统一。正文不用emoji、聊天引用块、卡片边框或装饰性分隔线。

## 三个必须一致的段落动作

**领句和解释同段。** 写成 `**直营渠道收入增长，门店扩张贡献主要增量。** 2025年……`。不要把加粗句单独放一行再留空行，也不要仅加粗“渠道端”。

**自然段之间用样式控制间距。** Markdown只用一个空行；Word用段前/段后间距。禁止用空白段落、连续回车或空格模拟排版。

正文如何展开机制、选择复句与安排小节递进，以 [chinese-sell-side-prose.md](chinese-sell-side-prose.md) 为准；本文件只约定其视觉呈现。

**正文有疏密变化。** 数据密集段可较长，转折或承接段可较短。不要一律压成三行，也不要强制每段凑满固定字数。正文图文交替，不把所有图集中于章末。

## 参考页面与中性版式的区别

抽样核对的参考页以A4纵向为主，正文中文约10pt，二级标题约12pt、一级标题约16pt，图表来源约8pt。若干页面的正文块相对全宽图表向右缩进，这是机构模板特征，不作为通用默认。样本字号来自PDF文字对象抽样；下列行距、边距等是便于中性输出的设计起点，并非对21份报告逐页测量的结论。

用户有明确模板时以模板为准。无模板的Word/PDF建议：

| 样式 | 中性默认起点 |
|---|---|
| 页面 | A4纵向，左右20mm、上下约20–22mm |
| 正文 | 中文宋体或可稳定渲染的Noto/思源宋体，10.5pt，两端对齐 |
| 首行 | 缩进2个汉字宽；10.5pt正文约21pt，不用全角空格代替 |
| 行距 | 约1.4倍或固定16pt，按中英文混排与渲染结果择一调整 |
| 段间 | 段前0pt、段后6pt；不叠加空白段落 |
| 领句 | 与正文同字号，加粗，不改变段落样式与缩进 |
| 一级标题 | 16pt黑体/无衬线加粗，段前14pt、段后8pt，与下一段同页 |
| 二级标题 | 12pt加粗，段前10pt、段后6pt，与下一段同页 |
| 图题/表题 | 9pt，段前8pt、段后3pt，与图表同页 |
| 来源/注释 | 8–8.5pt，单倍行距，段后6pt，随图表紧排 |

列表使用真实列表格式与悬挂缩进，续行与条目文字对齐，不沿用普通正文的首行缩进。英文和数字字体保持兼容、统一；不要因两端对齐把末行英文单词强行拉开。字体缺失时选择可用字体并重新渲染。

这些设置应在正文样式层实现，不能在每段手动反复设置。长自然段允许跨页并控制孤行；只将标题、题注和必要短块设置为与下段同页，避免整篇正文设置keep-with-next造成大片空白。

## 各区域的不同节奏

- 摘要：少量核心观点，每条“加粗完整判断+紧随的支撑文字”，可分项；不能把这种紧凑摘要格式套到全部正文。
- 公司/经营/行业正文：一至数个完整自然段后接最相关的图表。段首可概括，承接段可直接展开。
- 历史复盘：按阶段组织自然段；事件年表承接细节。
- 预测：可用“收入核心假设”“利润端假设”等小节，按业务或地区分项，各项仍有完整解释和预测数值。
- 风险：一项一个短段或条目，保留必要因果，不要求每项扩写成大段。

## 图表与文本

完整或详细报告先按 [chart-data-workbook.md](chart-data-workbook.md) 建立底稿。

- 每张图表回答实际研究问题，并紧邻支撑段落；可以先图后文，也可以先文后图。
- 正文解释趋势、结构、异常值和原因；关键数字可与图表重复出现，但不能逐年复读全部数据。
- 同主题、相同口径、能独立读清的两张小图可以并排。复杂分类、长历史序列、产品矩阵、预测及估值表优先全宽。
- 同页图表是否并排由可读性决定，不设置“每页必须若干张”的配额。
- 每张图/表/图片均有编号、标题、单位、期间和独立来源。来源在图表下，口径差异放注释中。
- 图表跨页时控制题注与来源；表格重复表头，不将一行拆到两页。长表可自然跨页，不为同页而缩到不可读。
- 数据图优先原生图表；颜色语义保持稳定，历史和预测可辨；避免3D、彩虹色及误导性双轴。

## 图片证据与数值表

产品、营销、门店图可作为证据，但须写明页面/店铺、地区、采集日期和样本范围。记录原始链接，不能将单店单时点图片外推成全市场销量或份额。技术宣传不等于经过验证的性能优势。仅复用有权使用的素材；不把参考研报中的人物照、水印图和数据库截图直接装入新报告。

数值表统一币种、期间、小数位和A/C/E。减少竖线，数值对齐，关键输出适度加粗。预测、可比估值、敏感性表必须与底稿一致。避免将大段文字塞进窄表格；有连续论证的内容留在正文。

## Word成品检查

用户要求DOCX时使用可用的文档制作能力和工作区依赖，制作后渲染全部页面；最终修改后再渲染。重点检查：

1. 领句实际加粗且与解释同段，目录没有混入段首句。
2. 正文首行缩进、行距、段后间距一致；列表悬挂缩进正确。
3. 标题不孤行，没有重复空段、异常大空白、每句话一个段落的现象。
4. 图题、图表、来源紧邻；并排图在100%缩放下可读。
5. 表格无截断，中文无缺字，中英文没有异常拉伸。
6. 页眉页脚、页码、目录、封面和正文数字一致。

不用参考报告的机构Logo、水印、分析师身份和合规声明。保留其正文节奏及层级即可，不复制整套机构识别系统。
