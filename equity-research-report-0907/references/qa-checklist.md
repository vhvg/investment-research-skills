# 交付前质量门槛

## 阻断项

先按任务范围筛选适用项目。纯润色不要求新建模型，局部章节不要求全报告封面/风险章，无估值任务不要求价格基准日；用户明确不需要底稿时按其范围交付。适用的阻断项未通过时不得把任务描述为完成：

- 核心结论缺乏可回溯证据或把推断写成事实。
- 存在未处理的 `[[占位符]]`、待核实数字或虚构来源。
- 数据截止日、价格基准日、币种或预测口径不明确。
- 图表、正文、模型和封面中的关键数字不一致；核心数值未经单位、期间和展示精度勾稽。
- 完整或详细报告包含图表，但未提供图表底稿；或报告图/表无法映射到唯一工作表。
- 估值没有方法、基准日、关键假设或股本/净债务桥接。
- 报告缺少风险与证伪条件。
- DOCX 未完成最终渲染检查，或存在遮挡、截断、缺字和不可读图表。

## 研究审计

- [ ] 研究问题和受众明确。
- [ ] 需要论证的核心假设可证伪，数量与问题相称；事实摘要不强建假设树。
- [ ] 核心证据优先来自原始资料。
- [ ] 事实、测算、预测和判断已区分。
- [ ] 来源冲突和资料缺口已解释。
- [ ] 每条主要判断有反方证据或替代解释检查。
- [ ] 当前信息已按数据截止日重新核验。

## 论证审计

- [ ] 标题和目录单独阅读即可理解逻辑。
- [ ] 每章都服务于核心论点、估值或风险。
- [ ] 核心论点在章节层面包含机制、证据、财务影响和验证边界；不要求每段重复完整链条。
- [ ] 市场共识与报告新增判断已分开。
- [ ] 催化剂包含时间、事件、预期影响和跟踪指标。

## 数字与模型审计

- [ ] 历史数据与披露一致，重述项目已说明。
- [ ] 分部、地区和渠道范围互斥，内部交易抵销后与集团口径一致；直营收入与加盟流水、产量与销量、期末门店与营业时间加权门店未混用，良率和爬坡未重复调整。
- [ ] 收入、利润、现金流和净债务桥接完整。
- [ ] A/E、财年、币种、单位、同比/环比和百分比/百分点一致。
- [ ] 预测假设具有历史锚点或外部依据。
- [ ] 情景方向合理，敏感性公式和每股价值无硬编码错误。
- [ ] 可比公司筛选、估值年度和异常值处理有理由。

## 图表与引用审计

- [ ] 每张图表有编号、标题、单位、期间和来源。
- [ ] 自行测算和预测已标记。
- [ ] 每张图表在正文中被解释。
- [ ] 图例、坐标、颜色和预测区可读且不误导。
- [ ] 截图包含平台、日期、样本和筛选条件。
- [ ] 引用定位足以让另一位研究者复核。
- [ ] `图表索引` 中每张报告图/表只出现一次，并对应唯一 `Fnn_`、`Tnn_` 或 `Inn_` 工作表。
- [ ] 每个图表工作表前六行按底稿指南填写原始 URL 或文件名、精确定位和证据编号；本地材料已实际打开复核，没有只写“公司资料”等模糊来源。
- [ ] 来源行以下的数据保持适合原始资料和分析目的的结构，没有为了套模板而强行使用统一列名、固定列数或固定方向。
- [ ] 数据图使用可复算数据和公式，未仅粘贴静态截图；图片的样本边界和复用限制已在证据台账或报告注释中记录。
- [ ] 报告图题、来源行、数字、A/C/E 标记和底稿索引一致，不存在孤立图表或孤立工作表。
- [ ] 关键图表工作表已渲染检查，数值和图形无截断。

## 编辑与成品审计

- [ ] 投资逻辑、预测和估值段前置结论；历史与经营复盘段在段内或紧邻段落完成阶段判断。
- [ ] 删除重复事实、空泛形容和无关历史。
- [ ] 公司、品牌、人名、币种和缩写拼写一致。
- [ ] 风险写明传导路径和观察指标。
- [ ] 封面、目录、正文、附录和来源清单完整。
- [ ] 分段撰写产生的章节已合并至唯一主稿，进度文件中的口径、图表编号和章节状态与主稿一致。
- [ ] 未伪造机构品牌、分析师身份、评级认证或合规文本。
- [ ] 对外部读者说明研究用途、数据截止日和关键限制。

## 语言与句法审计

- [ ] 每句可识别为事实、样本、测算、预测、判断或风险，措辞强度与证据层级一致。
- [ ] 常规成稿用“根据披露/样本显示/在假设下”自然区分认识层级，没有连续使用 `【披露事实】` 等审计标签。
- [ ] 关键数字写清主语、期间、口径和比较基准；连续句可以承接同一主语与期间，不重复全套定语。
- [ ] “我们认为/判断/预计”只用于跨越证据边界，没有成为段落起笔口头禅。
- [ ] 同一句没有叠加“可能、或将、有望”等多个不确定性标记。
- [ ] “主要系、受益于、带动、推动”后的因果有依据；仅作机制解释的潜在作用与已经实现的效果保持区别。
- [ ] 专业词准确对应经营含义：增量贡献与增长原因、提价与组合变化、费率摊薄与降本、投产与爬坡未混淆。
- [ ] 每段围绕一个中心问题，可同时包含事实和解释；仅在对象或主题变化时拆分，不因信息类型不同而逐句拆段。
- [ ] 长复句主干清楚，因果、比较与转折对象稳定；只在嵌套过多或转入新问题时拆句，不按长度一律截断。
- [ ] 相邻段落没有反复以“我们认为、同时、此外、其中”起笔。
- [ ] 标题及必要的段内领句给出对象与方向；固定功能标题、定义和自然承接段按内容处理。
- [ ] 删除“前景广阔、值得期待、持续赋能”等无法由事实证明的套话。
- [ ] 经营章节使用量价、品类、地区、渠道、客户、产能、店效或利润率等可验证变量，而非只写抽象“品牌力/空间”。
- [ ] 图表正文只解释趋势、结构和含义，没有逐项复读图中全部数字。

## 段落风格审计

- [ ] 主要分析段以完整概括句领起，常用加粗；没有普遍只加粗“产品端/渠道端”等空标签。
- [ ] 领句与解释处于同一自然段，不误用标题样式或拆成独立短段。
- [ ] 普通经营正文以连贯自然段为主；摘要、预测假设、风险的分项格式没有扩散为全文清单。
- [ ] 没有连续短句碎段、密集小标题或标题—领句—段尾重复判断。
- [ ] 段长按论证需要变化，没有为了达到建议字数填充材料或删掉关键数字。
- [ ] “事实—机制—投资含义—证伪”等内部检查标签没有进入成稿。
- [ ] 只做风格改写时，没有增补未经授权的事实、原因、预测或改变判断强度。
- [ ] 有资料时，机制已展开到订单、产品、渠道、工序或费用的实际过程；资料较少时没有用同义总结撑长。
- [ ] 相邻段落引入新环节、新证据或新比较，图表后没有重新介绍背景。
- [ ] 限制说明就近处理影响结论的边界，一般缺口未机械重复在每段末尾。
- [ ] 代表性小节先核来源与口径，再按语言指南连读；脚本通过只证明可检查项通过，不等于文风已得到验证。

## 图表底稿视觉与公式审计

- [ ] 所有报告图/表对应工作表均已逐张预览，数据和图形完整可见。
- [ ] 工作表结构保持轻量；顶部来源清楚，下面的数据和图形布局服从实际内容而非固定模板。
- [ ] 公式无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或意外循环引用。
- [ ] 历史、预测和一致预期具有稳定颜色/标记，单位和小数位一致。
- [ ] 关键假设位于可见单元格；其来源在证据台账或独立模型记录，公式中没有未说明的魔法数字。
- [ ] `scripts/validate_chartbook.py` 已结合适用范围的主稿执行；任何保留警告已有说明。已存储值的静态检查通过，不等于公式已重算或缓存有效。

## DOCX 视觉审计

- [ ] 页数符合预期，目录页码可更新。
- [ ] 首行缩进、行距、段后间距统一；列表悬挂缩进正确，没有空白段落模拟间距。
- [ ] 加粗领句为正文段内run，未混入目录；末行英文没有被两端对齐异常拉伸。
- [ ] 页眉、页脚、章节起始页和页码正确。
- [ ] 标题不孤行，图题与图表、来源与图表尽量同页。
- [ ] 表格允许自然增高并正确跨页，表头可重复。
- [ ] 没有缺失中文字形、文字重叠、图片变形或低清晰度。
- [ ] 100% 缩放下正文、图例、轴标签、脚注和来源可读。
- [ ] 最终一次修改后已重新渲染并逐页检查。
