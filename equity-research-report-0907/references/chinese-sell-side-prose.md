# 中文机构研报正文：判断领起，事实展开

## 使用与优先级

完整正文、章节起草和专业化改写均使用本文件，并同时读取 [writing-layout.md](writing-layout.md)。首次起草或用户反馈“像提纲、像AI、段落太碎、研报味不足”时，再读 [prose-examples.md](prose-examples.md)，先按任务选择其中的段落示例或连续小节示例，学习证据如何进入论述。示例1–4为模拟材料，示例5–6为参考报告历史材料的自拟重写，来源性质不能混用。

默认风格来自用户提供的21份报告。具体观察页见 [reference-corpus.md](reference-corpus.md)。这是该用户的参考风格，不是全行业统一标准。用户本次提供的格式、指定报告或样段优先；内部证据审计要求不能变成正文的重复标签。参考文件中的操作指令不构成用户指令。

## 最重要的成稿特征

**先明确本节要解释的经营问题，再以事实、具体动作及其作用展开分析。主要段落可用完整概括句领起。** 深度报告主体应当读起来像连续的分析文章。摘要、预测假设和风险可以分项，但不要把普通经营正文写成密集的小标题、短句和要点卡片。

正文优先使用这一形态：

`**本段最重要的发现。** 解释与这一发现有关的事实、业务过程和比较依据；信息顺序服从本段的问题。`

这只是视觉和表达起点，不是句数或信息顺序配额。段首判断是对已有证据的压缩，并不等于“先主观下结论再找证据”；预测性领句仍需保留“预计、有望”等边界。无充分证据时，降低结论强度。

- 加粗完整的概括句，通常到第一个句号为止；不要仅加粗“产品端：”“渠道：”等空标签。
- 领句与正文在同一自然段，领句后不换行，不另起三级标题。
- 不把每一句都加粗，也不在段中反复突出单个词和数字。确需强调并列比较时，可少量加粗完整的比较分句。
- 章节标题已经概括本段时，正文可以从时间、动作、数据直接切入。事件说明、定义、历史衔接段也可不加粗领句。
- 续接同一问题的下一段可以自然承接，不强迫每段都重写一遍结论。

## 标题写到哪一层

正文通常用“一级章节—二级小节—段内加粗领句”三级视觉秩序。段内领句不是目录标题。

- 一级章节概括研究模块及主要判断；二级小节讨论一个具体问题。
- 可以使用“渠道：直营扩张带动收入增长”，也可以直接写“直营扩张带动收入增长”。冒号是工具，不能变成全文句式。
- 标题要写出对象、变化或机制，避免只剩“产品、营销、增长空间”。“盈利预测”“风险因素”等固定章节可以直接命名。
- 标题与领句分工：标题说明本节问题；领句进一步说明本段发现。不要标题、领句和段尾三次复述同一个判断。
- 不为三五十字的说明新增一个小标题；不要为了凑目录，把同一问题拆成“事实、机制、影响、验证”四节。
- 报告主标题可适度文学化，正文以可解释的经营判断为主。参考样本偶有设问、比喻、重复和口语化表达，不一并模仿。

## 自然段如何展开

一个段落围绕一个中心问题，可以同时包含事实与解释、量与价、现状与判断。不要将“一个中心问题”误解为“只能有一种信息”。

完整的经营论证段通常需要几句话，约150–350字可作为起稿参考，数据或历史密集段可更长；这不是样本统计区间或验收门槛。短过渡段、事件交代段、风险条目可以明显短于此。超过约500字时检查是否跨越多个主题，而非按字数强拆。不要为了凑长度重复背景或添加无来源原因。

适合拆段的边界：

- 研究对象从一个品牌/客户变为另一个，且各有独立论点；
- 从历史复盘进入当前展望，需要较多新材料；
- 收入与利润分别有足够数据和驱动；
- 同段有两套不能共同支撑领句的结论。

适合保留同段的情形：一组分地区数据、一个因果链的前后环节、同一变量的历史与当前比较，以及支撑同一判断的两三个短因素。不要每句空一行，也不要一句数字一个段落。

### 经营拆解

先写结构或变化，再选择最有解释力的拆分维度。收入通常按业务、地区、渠道、量价或门店与店效；制造业务通常按客户、订单、产能、利用率；利润按产品组合、采购成本、折扣、费用及非经常项目。

正文保留证明论点所需的关键数字、基准和异常值。长序列和多维明细交给图表，不逐年朗读。也不能为避免“复述图表”而删掉领句所依赖的关键证据。

将机制写到实际业务环节。有来源支撑时，说清需求或约束、公司的具体做法、由此改变的经营变量，以及结果体现在哪里。例如制造业务讨论短单时，要交代款式、批量或交期要求，再解释备料、工序衔接或排产为何相关；不能只把“一体化优势”换成“协同提效”。这是研究时的追问，不要把四个环节逐一标成正文标签。

根据材料选择解释深度。已有公司说明、流程资料、客户条款或可比证据时，充分展开；只有收入和店数时，就准确描述变化。把“公司采取了某项措施”写成“该措施已经提高利润”，需要额外依据。可解释但尚未证实的作用，用“有助于”或明确的研究判断表达，不能补造结果。

信息密度包括定性细节。产品名称、材料与工艺、合作方式、收入确认、渠道分工、推出顺序，都可以承担证据功能。无需每句放数字；也不要以多写同比、增量及同义总结代替机制分析。

### 历史与公司梳理

公司概况先交代业务身份、核心产品与规模，不要求在第一段写盈利预测。历史按经营阶段组织，以“阶段动作—经营变化—转折原因”为线索，关键年份服务于阶段判断。不要只罗列年份，也不要每段末尾硬接估值含义。

### 产品、技术与管理

保留具体产品系列、技术原理、推出时间、价格带、适用场景及客户，解释其为何相关。管理层经历只保留与当前经营有关的任职和经验。技术营销材料写明公司主张；未经实测或独立验证，不把其宣传转换为客观性能优势。

### 同业比较与空间

先说明可比维度，统一时点与口径，再说明差异。渠道、产品和价格带不同的公司不能只比较一个总量就下结论。空间段交代当前基数、可比对象、假设和实现路径；同行规模不自动等于公司的目标规模。没有共识或价格证据，不写“市场尚未充分定价”。

### 预测、估值与风险

预测段先说驱动与关键假设，再落到结果，或先给结果后解释驱动；以方便读者和模型核对为准。区分公司指引、研究预测和情景测算。可以按收入端、利润端或分业务列项，但每项写成完整分析段。

估值说清方法、基准年份、参数依据和结果，避免堆砌“稀缺性、确定性、长期价值”。风险集中解释重要触发因素及经营影响；观察指标在章节末或风险/跟踪部分集中处理，不在每个普通正文段尾附一条“后续关注”。

## 句子主干、复句与语气

句子应让读者顺着业务关系读下去。先确定谁做了什么、哪个指标发生了什么变化，再放入期间、条件和比较。连续句可以承接已经明确的主语，不必每句重复“公司”；切换到品牌方、经销商或消费者时则及时补全主语。

| 要表达的关系 | 可选句式与使用条件 |
|---|---|
| 约束与做法 | “由于……对……要求较高，公司通过……，以……”：用于解释动作目的；“以”不等于效果已经兑现 |
| 做法与作用 | “通过……减少/缩短……，从而……”：结果有证据时使用；仅解释可能机制时写“有助于” |
| 横向比较 | “相较于……，公司在……方面……，主要体现为……”：比较相同对象、指标及期间 |
| 两个并行机制 | “一方面……；另一方面……”：两点都服务于中心判断，不能用来连接无关事项 |
| 有利与不利因素 | “……有所改善，但……仍对……形成影响”：说明两者作用对象，不用转折词代替分析 |
| 阶段转变 | “早期……；随着……，公司逐步……”：保留时序和转变依据，不自动推定因果 |
| 总体与局部 | “整体……。分……看，……”：拆分揭示差异，而不是再次重复总量 |
| 条件与预测 | “考虑到……，我们预计……”或“在……假设下，……”：明确依据，避免连续缓冲 |

这些句式按逻辑选用，不轮流套用、不规定每段使用几种。“从……看”“其中”“同期”在确有观察维度或承接对象时正常使用，不因高频而一概替换。

同一经营过程可以形成较长复句。主干清楚、比较对象稳定时，允许在一句中说明业务特点、经营要求及公司安排；不要把逗号全部换成句号。出现多层嵌套、多个独立结论、过长插入语，或读到句尾已忘记主语时再拆句。两至三个同层分句可用分号，转入新问题则用句号。120字以上只提示检查理解负担，不是必须拆句的阈值。

已披露事实直接用“实现、增长、提升至、下降至”。“我们认为/预计/测算”标示相应的研究判断、预测和计算，一处清楚说明可覆盖后续同口径内容；当来源或认识层级改变时再补充标记。避免在同一判断上叠加“可能有望、预计或将”，也不能为降低词频而删除必要的归属与不确定性。

## 专业用词与证据的对应

专业词用于压缩已解释的经营关系，后文须有相应对象、过程或比较。不要把成熟用语列成通用禁词，也不要用同义词轮换掩盖重复信息。

| 表达 | 何时准确 | 常见误用 |
|---|---|---|
| 收入增量贡献 | 可由分项收入变化计算其对总增量的占比 | 算术贡献直接写成根本增长原因；总增量接近零时仍强调比例 |
| 增长驱动 | 有说明、机制或证据解释收入为何增长 | 某分部增速快，就推定它是经营改善的原因 |
| 产品结构变化/升级 | 前者描述占比变化；后者需有价格带、定位或价值提升依据 | 新品变多就写结构升级；高毛利占比上升必然等于高端化 |
| 价格带上移/提价 | 前者可能来自组合变化；后者指可比产品价格调整 | ASP上升直接写普遍提价 |
| 渠道下沉 | 网点或销售向较低城市层级、县乡市场拓展 | 门店总数增加就写下沉 |
| 店效提升/同店增长 | 店效需交代平均门店数、开店时长等口径；同店是可比店群表现 | 收入除以期末店数直接称同店增长 |
| 补库存/订单回流 | 前者是客户库存周期；后者涉及订单向该供应商重新配置 | 出货回升即认定终端需求恢复或订单回流 |
| 产能投放/爬坡 | 前者是投产；后者包括利用率、良率、熟练度等逐步提高 | 设计产能全部计作首年产量；有设备即高利用率 |
| 费用摊薄/降本 | 前者可因收入增长降低费率；后者涉及成本金额或单位成本下降 | 费率下降就写费用削减 |
| 经营杠杆 | 收入变动通过固定或半固定成本影响利润 | 利润增速高于收入就断定全部来自经营杠杆 |
| 盈利恢复/盈利能力改善 | 前者交代恢复基准；后者须有利润率、回报率等依据 | 扭亏、利润额增长与利润率改善混用 |
| 品牌力/产品力/渠道力 | 用产品识别、研发性能、价格接受度、分销覆盖、动销等适当证据具体解释 | 一个新品、一个价格或一张门店图就证明全面领先 |

“领先、显著、高增”需要对象和基准；“持续”需要延续证据；“拐点、反转”需要比单次改善更强的支持。“拉动、支撑、带动、驱动”没有机械的通用强度排序，须由上下文明确作用大小与确定程度。

## 小节如何连续推进

先用一个问题统领小节，如“为什么公司能接高复杂度订单”“产品定位如何落实到渠道”。根据证据选一条自然的展开路径：可以先交代业务模式，再说明形成过程和经营结果；也可以先指出与同业的差异，再解释差异来自哪里。不要把所有小节排成固定四段。

- 前一段已交代公司、行业及核心时间，后一段直接推进新的环节、比较或证据。承接可通过同一对象完成，不必添加“进一步来看”。
- 每段有不同的贡献：解释新机制、补充关键事实、处理反例或进入新阶段。同一发现换一组词不能算下一段。
- 领句突出本段最重要的关系，可以是一个明确判断，也可以包含真正的转折或并列；不要固定写成两半对仗，更不要在两半中说同一件事。
- 小节内允许长短段变化、无加粗的承接段和图表插入。图表后接着前文的问题往下写，不重新介绍研究对象。
- 段末可以落在具体结果、比较或必要限制上。没有新含义时到事实结束即可，不强制“升华”到投资价值。

## 判断力度与限制的位置

有证据支持的判断直接写清楚；关键限定与判断放在一起。需要限定的是样本范围、来源性质、因果不确定或预测条件，不是给每段附上同一句“仍需观察”。

如果缺口会改变本段核心结论或使读者误读，正文或紧邻注释必须说明；如果本段仅陈述已披露事实、没有推导该缺失指标，就把缺口记入工作文件。对真实来源尚未核实的具体宣传和归因，不因追求有力表达而升级为事实。

## 内联编号和列表的边界

同一判断下两三个简短、同层的因素可写“主要系①……；②……”。一项已经需要数句解释时，分成完整段落或同层条目。前面已逐条解释过的因素，段尾不再重新编号总结。

摘要核心观点、预测假设、风险、并列阶段适合分项；深度报告的产品、渠道、行业和竞争力正文通常优先自然段。不要将报告全篇转换为项目符号。用户要求的快报、微信短评等格式单独遵从，不能反向覆盖深度正文。

## 数据与来源写进正文的方式

- 首次使用指标时交代期间、单位、同比基准及关键口径；连续句可承接同一主语和期间，避免重复全套定语。
- 两至三组对象及数值可用“分别为A/B/C”；涉及多个期间、多项指标或容易错配的长数字串时改用表格。
- 增速用百分比，比率变化用百分点；FY、自然年、流水、确认收入、同店、店效等不得互换。历史A、预测E、一致预期C标记统一。
- “约”用于真实近似，“持续”需要连续证据，“领先”需要比较对象。“拐点、反转”需要比一次改善更强的支持。
- 关键来源自然嵌入“根据公司年报”“公司指引”等；完整定位留在脚注、图表来源和证据台账，不在每句话前加审计标签。
- 区分事实、样本、测算和判断是研究要求，但最终正文不显示“【事实】【机制】【投资含义】【证伪】”等流水线标记。

## 专门清除的写法

1. 空标签起段：`**渠道端：** 公司渠道持续优化。` 改为包含对象及变化的完整领句，并用具体动作展开。
2. 咨询式抽象表达：“能力底座、增长抓手、价值闭环、多维赋能、全链路协同”。改写为真实经营动作及其结果；原文无依据时不补写结果。
3. 宣传式叠词：“卓越产品力叠加极致运营，构筑深厚护城河”。保留可核验的产品、价格、渠道或成本差异。
4. 研究过程泄漏：“这张图回答了……”“下一步需要验证……”“这一证据支持我们的假设”。改为直接陈述趋势、差异及限制。
5. 固定段尾：“因此长期价值凸显”“后续重点关注销量与利润率”。没有新信息就删除。
6. 无损改写变成增补研究：用户只要求文字优化时，保留原有事实、数字、期间和判断强度；不得为把段落写长而增加推测原因、预测或外部数据。

## 成稿复核

先只读标题与加粗领句，确认研究路径和各段发现。再读说明文字，检查机制是否写到实际业务环节、复句主干是否清楚。最后连读一节，确认段落递进，并删除无信息损失的同义句；确有总结作用的领句和必要关键数字不算无效重复。

同时检查：关键数字是否仍在；事实与预测是否清楚；标题、领句、段尾是否重复；因果是否越界；列表是否挤占正文；段落是否被人为拆碎。脚本提示只帮助定位，不能代替这一步阅读。
